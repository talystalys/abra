## 3. Key Observations
1. **Zero Spills**: All four variants achieve zero local memory spill stores and zero spill loads on both architectures.
2. **Register Allocation**: Variants A, B, and C on Pascal maintain $\le 32$ registers per thread, enabling 100% theoretical SM occupancy.
3. **Shared Memory Staging**: Variant D requires 55 registers per thread and 2048 bytes of shared memory per block, lowering SM occupancy on Pascal to ~58.6% due to register limits.
