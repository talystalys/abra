## 4. Technical Assessment
1. Modern NVIDIA drivers (550.x) restrict non-root hardware performance counter access (`ERR_NVGPUCTRPERM`).
2. Pascal SM 6.1 (`sm_61`) has deprecated / unsupported hardware counter profiling in CUDA 12.9+ Nsight Compute toolchains.
3. In accordance with Section "PROFILING" of the M2 project charter, system modifications (modifying driver kernel module parameters or downgrading toolchains) are prohibited.
4. Primary execution metrics remain strictly grounded in high-precision CUDA event timing (`cudaEventElapsedTime`), ptxas resource usage accounting, and SASS disassembly analysis.
