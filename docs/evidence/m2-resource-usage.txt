## 3. Key Observations & Physical Limiting Factors
1. **Zero Register Spills**: All four kernel variants compile with exactly 0 spill stores and 0 spill loads to local memory on both architectures.
2. **Occupancy on Pascal**:
   - Variants A, B, and C strictly maintain $\le 32$ registers per thread, permitting the maximum block count (16 blocks of 128 threads or 8 blocks of 256 threads) to achieve full **100.0% theoretical occupancy** (64 resident warps per SM).
   - Variant D uses 55 registers per thread ($14,080$ registers per 256-thread block), restricting each SM to 4 active blocks ($1,024$ resident threads = 32 resident warps), yielding exactly **50.0% theoretical occupancy**.
